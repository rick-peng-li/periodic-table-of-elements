# periodic-table-of-elements

一个交互式元素周期表，使用纯 HTML/CSS/JavaScript 实现。

## 功能特性

- **完整元素数据**：包含全部 118 个元素
- **元素信息展示**：原子序数、元素符号、中文名称、原子量
- **分类着色**：按元素类型进行颜色区分
  - 碱金属、碱土金属、过渡金属、后过渡金属
  - 类金属、非金属、卤素、稀有气体
  - 镧系元素、锕系元素
- **交互效果**：
  - 鼠标悬停放大效果
  - 跟随鼠标的发光效果
  - 不同元素类型对应不同发光颜色

## 技术实现

- 纯前端实现，无需后端支持
- CSS Grid 布局
- CSS 变量实现动态发光效果
- JavaScript 动态生成元素卡片

## 使用方法

直接在浏览器中打开 `index.html` 文件即可查看。

## 浏览器支持

支持所有现代浏览器（Chrome、Firefox、Safari、Edge）。
